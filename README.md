# Ouro UI for Apple

The Swift package for **Ouro HX** (for people) and **Ouro AX** (for agents), for Apple platforms. Under construction: the products land in the first pull requests, then `v0.1.0`.

Tokens come from [ouro-ui-core](https://github.com/ourostack/ouro-ui-core) v0.1.0; see `core-provenance.json`. Read `AGENTS.md` before changing anything.
