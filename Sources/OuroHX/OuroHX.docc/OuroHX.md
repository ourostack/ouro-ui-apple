# ``OuroHX``

Ouro HX for Apple: the tokens from ouro-ui-core v0.3.0 and the SwiftUI pieces that use them.

## Overview

Theme a view tree once and read the colours anywhere below it:

```swift
ContentView()
    .ouroTheme(.pearl)

struct Badge: View {
    @Environment(\.ouroColors) private var colors
    @Environment(\.ouroTheme) private var theme
    var body: some View {
        Text("New")
            .foregroundStyle(colors.primaryForeground)
            .padding(6)
            .background(colors.primary, in: .rect(cornerRadius: theme.radius(.md)))
    }
}
```

The token file `OuroTokens.swift` is generated by core and vendored byte for byte; `core-provenance.json` pins its
hash and CI checks it against the core release.
